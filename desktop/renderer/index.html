Die Live-Verbindung zu einer geöffneten Studio-Place funktioniert auch ohne API Key. Der Key wird niemals in den Arena-Prompt oder den Cloudflare-Tunnel geschrieben.

Tutorial: Key für Blender-Mesh-Uploads einrichtenSchritt für Schritt
  1. Creator Dashboard öffnenBei Roblox anmelden und unter Open Cloud → API Keys auf Create API Key klicken.
  2. Key benennen und Creator wählenZ. B. Arena Blender Meshes. Wähle deinen eigenen Account oder nur die Gruppe, in deren Inventar die Modelle hochgeladen werden dürfen.
  3. Assets API hinzufügenUnter Access Permissions bei Select API System die Option Assets wählen und auf Add API System klicken.
  4. Diese zwei Rechte einschaltenBei den Assets-Operations Read und Write aktivieren. Write lädt das Modell hoch; Read liest den Status der Upload-Operation und die Asset-ID.
  5. Sicherheit einstellenIP-Beschränkung möglichst auf deine feste öffentliche IP setzen. Bei wechselnder IP den Schalter Restrict IP addresses aus lassen. Ein Ablaufdatum ist empfohlen, aber optional.
  6. Key erzeugen und hier speichernAuf Save & Generate Key klicken, den einmalig angezeigten Key kopieren und oben einfügen. Danach unten Creator-ID und Blender-Pfad konfigurieren.
